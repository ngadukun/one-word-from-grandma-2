One word from Grandma. Her whole vocabulary of concern, compressed to a single syllable that is at once a greeting, a diagnosis, and an order — she says it before hello, after goodbye, and instead of "I love you":

> **Eat.**

## Run it

```sh
python3 main.py
```

Prints `Eat.` to stdout and nothing else. Python standard library only, deterministic, no files written.
